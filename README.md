# 차례상 타이쿤

애미야, 국이 짜다! 어머님 손바닥을 피해 추석을 살아남는 풍자 타이쿤 게임.

- 1부 음식 장만: 장보기, 전 부치기, 탕국 끓이기
- 2부 차례상 차리기: 어동육서, 두동미서, 좌포우혜, 조율이시, 홍동백서 (새댁 · 10년차 · 종부 모드, 지역별 법도)
- 3부 차례 지내기: 강신부터 음복까지 순서 맞추기
- 4부 잔소리 방어전: 친척 질문에서 멘탈 지키기

플레이: https://chewrispy.github.io/charye/

## 안드로이드 앱

`main`에 코드를 올리면 GitHub Actions가 안드로이드 테스트 앱(APK)을 자동으로 만들어요.

- 받는 곳: 이 저장소의 Releases → **안드로이드 테스트 빌드** → `charye-test.apk`
- 갤럭시에서 처음 설치할 때 "출처를 알 수 없는 앱 설치"를 한 번 허용해야 해요.
- 앱에서는 구글 폰트 대신 앱에 내장된 폰트(주아, 고운돋움)를 써서 인터넷 없이도 동작해요. 웹 버전(`index.html`)은 그대로예요.
- 앱 ID: `bomi.charye` (플레이 스토어에 처음 올리기 전까지만 바꿀 수 있어요)
- 출시용 `charye-release.aab`는 `release/upload.jks`(업로드 키)로 서명돼요. 키 비밀번호는 저장소 시크릿 `ANDROID_KEYSTORE_PASSWORD`에만 있어요. 이 키는 플레이 앱 서명의 "업로드 키"라서, 잃어버려도 플레이 콘솔에서 재설정을 요청할 수 있어요.
